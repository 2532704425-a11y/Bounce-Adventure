# 弹跳大冒险

《弹跳大冒险》是一款移动端 H5 休闲小游戏。玩家通过拖拽蓄力进行弹射，探索关卡并收集鸡腿。

## 玩法

- 寻觅鸡腿：完成弹射、反弹和收集挑战。
- 营救鸡腿：利用重力与二段跳向上闯关。
- 无限模式：在十字地图中对抗持续出现的敌人。

## 性能优化

- 图片统一采用 WebP，并按显示尺寸缩放。
- 关卡卡片延迟加载；背景、敌人和地图资源按需加载。
- 关卡背景缓存受限，减少移动设备内存占用。
- 菜单与选择页不执行无意义的 Canvas 持续绘制。
